# Rock-Paper-Scissors Game

A fun and interactive Rock-Paper-Scissors game built with vanilla JavaScript and HTML. Play against the computer in a best-of-5 series with a graphical user interface.

## Features

- **Interactive UI**: Click buttons to make your choice and see results instantly.
- **Score Tracking**: Keeps track of scores up to 5 points, declaring a winner when reached.
- **Game Over Logic**: Disables buttons and announces the winner at the end.
- **Responsive Design**: Simple styling that works on different screen sizes.

## How to Play

1. Open `index.html` in your web browser.
2. Click one of the three buttons: Rock, Paper, or Scissors.
3. The computer makes a random choice, and the result is displayed.
4. First to 5 points wins! The game ends automatically.
5. Refresh the page to play again.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)

## Project Structure

- `index.html`: The main HTML file with the game interface.
- `index.js`: JavaScript logic for game mechanics and event handling.
- `style.css`: Basic styling for the UI.
- `README.md`: This file.

## Running Locally

1. Clone or download the repository.
2. Open `index.html` in a modern web browser.
3. Alternatively, serve it with a local server (e.g., `python3 -m http.server`) for better compatibility.
